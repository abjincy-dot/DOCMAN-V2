How to Use DOCMAN
🏢
Departments — Tap a department on the home screen to open its folders. Tap Add Department at the bottom to create a new one.
📁
Folders — Organize documents into folders and subfolders. Use Add Subfolder, Rename Folder, and Delete Folder from inside any folder.
⬆️
Upload — Tap Upload inside a folder to add a file from your Photo Library, Camera, or Files.
📄
Viewing PDFs — Tap any file to open it. Pinch to zoom, use the rotate button for landscape drawings, and the mark tool to circle a spot to point something out. If a PDF has a table of contents, a bookmarks button lets you jump between sections.
📝
Notes — Switch to the Notes tab to write and save quick text notes inside any folder, alongside your files.
🔍
Search — Use the search bar to quickly find a file or note by name without digging through folders.
✋
Rename, Delete & Favourite a File — Long-press any file or note to bring up a quick menu with Favourite, Rename, and Delete options.
⭐
Favorites — Favourited files and notes are pinned together under Favorite on the home screen for one-tap access.
⚙️
Settings — Tap the gear icon for backup & restore and other app preferences.
